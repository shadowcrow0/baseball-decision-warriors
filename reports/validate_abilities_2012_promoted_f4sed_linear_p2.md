# 四種能力 × Statcast 物理量：2012 年 promoted_f4sed_linear_p2

分數來自 2012 年小聯盟成績單；物理量是同一人登上大聯盟後前 3 年的 Savant 排行榜平均。Spearman 相關，n = 同時有兩者的人數。

讀法：每一列是一個物理量，四欄是四種能力各自的相關。對角線（跑得快×衝刺速度、打得遠×初速、打得到球×揮空率為負、選得到球×追打為負）應該最大，非對角線接近零。
