# 主張地圖：每一個主張靠哪支程式、建立在什麼假設上、怎麼驗證、驗證之後多做了什麼（2026-10-27）

讀法：每一節是投影片上的一個主張。「假設」是這個主張成立的前提；「驗證」是我們做了什麼去確認前提；「因此多做」是驗證結果逼出來的新工作。箭頭 `→` 表示「這件事的輸出是下一件事的輸入」。程式都在 `src/`，輸出都在 `outputs/`，數字在 `docs/findings.md`。

## 0. 整條管線的依賴圖

```
fetch_minors / fetch_draft / fetch_war / fetch_ids / fetch_savant_*      （抓四個公開來源）
        ↓ check_sources → check_data（121 項檢查）
clean_minors → build_model_table（一人一季一列、分子＋分母）→ data/model_bat.parquet
        ↓                                              ↘ link_draft（選秀接 id）→ Part I（朋友的六頁）
fit_year.py  每季一次：測量層（15 數字 → 4 把尺）＋ 結構層（升級 ／ 登上時間＋WAR）
        ↓ eta_M1.parquet、lambda_M1.csv、struct_M1.csv、org_M1.csv、summary.md
        ├─ all_years / all_seasons（跨季合併）→ 第 15、16 頁

        ├─ war_decompose（WAR 拆四塊）→ 第 17 頁
        ├─ watchlist（真相的尺 vs 球隊的尺，名單）→ 第 18、26 頁
        ├─ sim_policy（反事實名單）→ 第 19 頁；forward_check（參考季權重搬到別季）→ 第 29 頁
        ├─ discipline_split → 第 20 頁
        ├─ misplaced_profile ＋ validate_defense → 第 21 頁
        ├─ club_features → club_need ＋ fit_year --club ＋ org_background ＋ org_rulers → 第 22 頁

        ├─ decision_bayes（五種決策程序）→ 第 24 頁

```

## 1. 「成績單量得到四把尺，而且是球探的尺」（第 13、14 頁）

| | 內容 |
|---|---|
| 主張 | 十五個公開數字可以拆成打得到球、打得遠、跑得快、選得到球四把尺；這四把尺就是球探的 20–80 工具加上選球。 |
| 程式 | `fit_year.py` 測量層（`assign_indicators`、`build`）；`profile_variables.py` 決定每個數字的似然（二項／負二項）。 |
| 假設 | (a) 每個數字事先歸屬哪把尺是對的（驗證性，不是探索性）；(b) 數字是「分子 ÷ 分母」的計數，打席少的人自然更不確定；(c) 四把尺之間可以相關。 |
| 驗證 | `validate_abilities.py`（經 `all_seasons.py` 跑 17 季）：四把尺對登上後 Savant 量到的物理量，跑得快 ↔ 衝刺速度 0.65、打得到球 ↔ 揮空率 0.61、選得到球 ↔ 追打 0.52、打得遠 ↔ barrel 0.44，17 季同號；交叉格 < 0.2。探索性因子分析只用來確認 15 個數字撐得起 4 維。`sim_recover.py`：負荷量偏差 ≤ 0.005。 |
| 因此多做 | 驗證看到打得到球 ↔ barrel −0.35（打得到球的人不硬打）→ 加了第五把尺「擊球品質」（`--factors 5`，第 8 節）。守備、臂力沒有數字 → 第 21 頁用登上後 OAA 間接驗證「球探看到的是守備」。 |

## 2. 「球隊升人看打得到球、打得遠、球探評價；扣選球」（第 15 頁）

| | 內容 |
|---|---|
| 主張 | 十七季的升級權重：三把尺正、選球負；打得到球的權重翻倍，選球的扣分從 −0.5 縮到 −0.07。 |
| 程式 | `fit_year.py` 結構層（升級段）→ `struct_M1.csv`；`all_years.py` 把 17 季排在一起。 |
| 假設 | (a) 每季各自估，不共用先驗（讓漂移看得見）；(b) 升級 = 隔年主要層級比今年高；(c) 球探評價（順位、簽約金）已經控制，權重是「成績單之外的加權」。 |
| 驗證 | 同號 17/17（`all_years`）；`bayes_factors.py` 每季每把尺 Savage–Dickey BF；十分位校準 ±0.07（`ability_stability.py`）；留一法比三個模型（成績單直接進、四把尺、wOBA 多項式）四把尺不輸；`forward_check.py`：2010／2015／2019／2023 四季的權重原樣搬到其他 13 季，只重估截距，保留 94% 的預測力（AUC 差 ≤ 0.015），折扣係數 0.96–1.33。`sim_recover.py` 主模型 20 複本：四把尺權重偏差 ≤ 0.04、涵蓋率 0.86。 |
| 因此多做 | 「球隊的尺在學」這句來自漂移 → 第 25 頁結論把球隊寫成方向對的一方，不是被罵的一方。`ppc.py` 發現二項過度離散 1.4–1.9 倍 → `sim_recover` 加 beta-binomial 真相的 20 複本，確認權重不偏、只有區間偏窄。 |

## 3. 「真相要的跟球隊大致一樣，只有選球不同」（第 16 頁）

| | 內容 |
|---|---|
| 主張 | 同一組四把尺拿去預測幾年後登上與登上後六季 WAR，打得到球、球探、打得遠、跑得快同序；選球上得慢、WAR 零；年資上得慢、WAR 低。 |
| 程式 | `fit_year.py --outcome war`（兩段：登上時間 log-normal 設限、WAR asinh-t）→ 13 季；`all_years.py` 合併。 |
| 假設 | (a) 六季窗口夠長（所以只有 2007–2019 可用）；(b) WAR 用 asinh 尺度 t 分布（一半人 ≤ 0，有人 20+）；(c) 沒登上的人 WAR 計 0 由第一段處理。 |
| 驗證 | 13 季同號；`sim_recover.py` WAR 段 20 複本：十個權重偏差 ≤ 0.04、涵蓋率 0.87，只有 ν 估高（5 → 6.2）。`ppc.py` WAR 段：WAR ≤ 0 比例真實 49%、模型 35%，t 不合。 |
| 因此多做 | ppc 的 WAR 不合 → 第 28 頁明寫、修法（兩段式 WAR）排在賽後；sim_recover 第一版 WAR 段全炸（`tau_org` 節點名有 `t_`/`w_` 前綴）→ 修程式重跑 20 個。 |

## 4. 「打擊率是門票：買到的是機會，不是產出」（第 17 頁）

| | 內容 |
|---|---|
| 主張 | 控制四把尺和球探評價後，打擊率高的人多拿五種機會，但每打席的產出沒比較好、守備更差。兩個人 A .310 / B .260：升級 67% / 47%，登上 20% / 10%。 |
| 程式 | `war_decompose.py`（六季 WAR 拆成打擊、跑壘、守備、上場機會四塊，再拆機會的五個零件，殘差對候選欄位相關）；A/B 兩人版是 2015 年 2,065 人季的 logistic（本機算，記在 findings §3）。 |
| 假設 | (a) 「控制四把尺後打擊率的殘差」代表「數字本身」而非能力；(b) 六季 WAR 可以線性拆成四塊（FanGraphs 的成分可加）。 |
| 驗證 | 殘差對機會五項相關 +0.12 到 +0.18、對每 600 打席 WAR ≈ 0、對守備 −0.22（都標 * 顯著）；`ability_stability.py` 17 季版：成績單殘差對登上 +0.56（z 24）、對 WAR +0.16（z 8.8），三倍多。 |
| 因此多做 | 這是第 25 頁三句結論的中間那句，也是第 26 頁第 4 條（升人會議看能力分數不看打擊率）的根據。守備那塊 → 第 5 節。 |

## 5. 「球探看到的是守備」（第 21 頁）

| | 內容 |
|---|---|
| 主張 | 模型不看好、球隊升、後來成功的人，守備好六倍；捕手靠守位上去；打擊率越高守備價值越低。 |
| 程式 | `misplaced_profile.py`（四群比對：模型與球隊意見不同的人長什麼樣）、`validate_defense.py`（登上後 FanGraphs 純守備分與 Savant OAA 直接量）、`war_decompose.py` 守備殘差。 |

## 8. 「缺什麼補什麼不成立，塞車的是人」（第 22 頁）

| | 內容 |
|---|---|
| 主張 | 母隊守位缺口對升級零；農場同守位比他好的人每多一個標準差，六季內登上 −0.33；三十隊的尺幾乎一樣。 |
| 程式 | `club_features.py` → `club_need.py`（個人層）、`fit_year.py --club`（球團截距分成母隊強弱、農場人才、殘差）、`org_background.py`（截距的背景，13 季合併 R² = 噪音）、`org_rulers.py`（每隊自己的尺，`--org-slopes` 跨季合併 BF）、`club_risk.py`（強隊弱隊偏好型態）、`slope_by_group.py`。 |

| 驗證 | `bayes_factors`／`club_risk`：六個交互項 × 三個結果 BF10 全在 1/10–1/49（支持零）。`sim_recover` 球團斜率 10 複本：σ_org 估得回來，**個別球隊偏離只相關 0.35**；球隊 × 型態 5 複本：**交互作用認不出**（−0.3 估回 0，r-hat 1.67）。 |

## 9. 「Statcast 沒有帶來新的一把尺」（第 23 頁）

| | 內容 |
|---|---|
| 主張 | 七個逐球量都落到成績單已有的尺上，原本負荷量不變；猜明年升不升多 0.02 AUC，對 WAR 零。 |
| 程式 | `fetch_savant_minors.py`、`hit_profile_statcast.py`、`dist_profile.py`／`dist_shapes.py`（分布形狀）、`fit_year.py --statcast add/same/only/both`、`compare_fits.py`（兩個 fit 的負荷量與 β 後驗並排）、`statcast_vs_rulers.py`（同一批 430 人 5 折 × 20 次樣本外）、`learn_weights.py`（先在大聯盟學權重再套回 3A）。 |
| 假設 | (a) 3A 2023–2024 的 430 人代表「有 Statcast 的聯盟」；(b) 「同一把尺」= 加進去後原負荷量不變且新指標載到既有尺上。 |

| | 內容 |
|---|---|

## 11. 兩個模型的整體檢查（第 28、29 頁）

| 檢查 | 程式 | 問什麼 | 結果逼出什麼 |
|---|---|---|---|
| 後驗預測檢查 | `ppc.py --all` | 模型生的資料跟真的像不像 | 八個數字過度離散 1.4–1.9 倍、WAR 的 t 不合 → beta-binomial 真相的還原、兩段式 WAR 排賽後 |
| 參數還原 | `sim_recover.py`（115 複本，8 種模型） | 真值已知估不估得回來 | 主線模型可信；Statcast 子樣本權重、球隊 × 型態交互作用不可信 → 不拿來下結論 |
| 程序還原 | `sim_decision.py`（20 複本） | LOO 認不認得出真程序 | WADD 不被偏袒；exemplar 認不出 → 主張收窄 |
| 證據強度 | `bayes_factors.py`、`bf.py` | 「有沒有效果」用 BF 不用 p | 支持零的結果（缺什麼補什麼、強弱 × 型態）可以講出來 |
| 收斂 | `fit_year` 的 r-hat、divergence | 抽樣可信嗎 | divergence 0、r-hat ≤ 1.04；f4sk 1.67 → 棄用 |
| 跨季可攜 | `forward_check.py` | 參考季的權重搬到別季還能不能預測 | 保留 94%：權重是行業的，不是某一年的 → 第 29 頁一句 |
| 樣本外 | `statcast_vs_rulers.py`、`decision_style.py` | 5 折、前三季估當季 | 第 23、24 頁 |

## 12. 跑過但沒進投影片的（為什麼）

- `variable_hunt.py`：四把尺之外一個一個加候選變數，前三季估第 t 季測；結論是四把尺之外只有打席、年齡有穩定增量，已經在共變數裡 → 不另立主張。
- `eta_quantiles.py`：四把尺後驗的十分位，問球隊買的是平均還是分布；BF 支持「買平均」→ 併入第 22 頁一句。
- `disagree.py`：wOBA 成分各自推動什麼 → 用於留一法比較（四把尺 vs wOBA 多項式），只在第 29 頁一行。
- `hit_profile.py`、`profile_extra.py`：打擊樣貌（點、拉打）與資料剖析 → 進第 13 頁「十五個數字」的選擇。
- `fetch_payroll.py`、`fetch_register.py`：薪資與體系外軌跡；薪資不分析（決定不做），體系外軌跡只用在陳品捷的案例。
- `decision_style.py`：貝氏版 `decision_bayes` 取代，保留作交叉檢查。
