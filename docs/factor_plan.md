# Factor 企劃書：為什麼拆成四個、怎麼拆、怎麼驗證

> 2026-10-07。對應 `fit_year.py` 的 `INDICATORS`、`ANCHORS`、`CROSSLOADS`、`FOLD`。本文件把拆 factor 的證據與定義存檔，供 model comparison 與簡報引用。

## 1. 起因：單一 factor 收斂失敗，而且失敗的方式有訊息

2015 年打者、13 個指標、單一 factor 的快速擬合（200+200×4 鏈）：

| 現象 | 數字 |
|---|---|
| 負荷量 r-hat | 1.73–1.85（全部） |
| 負荷量 ESS | 6（四條鏈各自卡在一個地方） |
| 結構係數（age、pick、PA）r-hat | 1.00–1.01，正常 |
| 負荷量後驗均值 | 全部接近 0，sd 大 |

結構部分收斂、測量部分不收斂，表示問題不在取樣器，在模型：四條鏈各找到一個「合理的 η 方向」，彼此不同，平均起來負荷量互相抵消。這是**多維度資料被壓成一維**的典型症狀。棒球常識也支持：三振多的人往往全壘打也多，一個「能力」分數同時要讓三振率負、全壘打率正，兩者卻正相關，一條線放不下。

## 2. 探索性因子分析（EFA）：資料本身有幾個維度

樣本：2007–2019 年、PA ≥ 150 的人季，比例在層級 × 球季內標準化（去掉環境差異），13 個指標，31,380 人季。EFA 只用來決定結構，不進最終模型（最終模型是貝氏 GLM 因子分析，見第 4 節）。

### 2.1 相關矩陣裡的群

| 群 | 指標 | 群內相關 |
|---|---|---|
| 接觸 | AVG、OBP、K%、whiff% | AVG–OBP 0.77；K%–whiff% 0.78；AVG–K% −0.43 |
| 力量 | XBH/H、HR/AB、Pull%、GB% | XBH–HR 0.73；XBH–GB −0.56；HR–GB −0.48 |
| 速度 | SBA/OBT、3B/H、SB%、GDP/AB | SBA–3B 0.32；SBA–GDP −0.28；SBA–SB% 0.25 |
| 跨群 | K%、whiff% 與 XBH/H、HR/AB | 0.27–0.39（三振與力量同向） |

速度群內相關弱（0.25–0.32），但與其他兩群幾乎正交（|r| < 0.25），是獨立的方向。

### 2.4 選球是不是第四個維度

加入壞球率（Ball% = Balls/Pitches）與每打席投球數（P/PA）後，對選球候選 + 接觸 + 力量八個指標做 EFA（33,037 人季）：

| 指標 | F1 選球 | F2 接觸（反向） | F3 力量 |
|---|---|---|---|
| BB% | **−0.91** | −0.04 | 0.00 |
| P/PA | **−0.77** | 0.43 | 0.07 |
| Ball% | **−0.94** | −0.22 | 0.06 |
| HBP/PA | −0.04 | 0.01 | 0.29 |
| AVG | 0.06 | −0.58 | **0.65** |
| K% | −0.10 | **0.95** | 0.06 |
| whiff% | 0.33 | **0.86** | 0.12 |
| HR/AB | −0.12 | 0.32 | **0.83** |

特徵值 2.47、2.32、1.19、0.99：三個清楚的成分。BB%、Ball%、P/PA 形成一個獨立且很緊的群（BB%–Ball% 0.87），與接觸、力量都幾乎正交。所以選球是第四個 factor，不是接觸的一部分。P/PA 同時載在接觸（0.43，看得多也三振得多），是第二個交叉負荷。HBP/PA 哪裡都不屬於，不用。

## 3. 四 factor 定義

| factor | 指標（分子/分母、似然） | 符號錨 | 棒球意義 |
|---|---|---|---|
| **contact 接觸** | AVG H/AB、OBP OB/PA、K% SO/PA、whiff% whiff/Pitches（皆二項） | K% 負 | 把球打進場、不被三振 |
| **power 力量** | XBH/H、Pull%/BIP、GB%/BIP（二項）；HR/AB（負二項，offset log AB） | HR/AB 正 | 擊球品質與長打 |
| **speed 速度** | SB%/SBA、SBA/OBT、3B/H、GDP/AB（二項） | SBA/OBT 正 | 跑壘：盜壘意圖與成功、三壘打、避免雙殺 |
| **discipline 選球** | BB%/PA、Ball%/Pitches（二項）；P/PA（負二項，offset log PA） | BB% 正 | 不揮壞球、拉長打席 |

交叉負荷（`--crossload`）：K%、whiff% 另載於 power。2015 試跑兩者各 +0.22（力量型打者三振多）；原本也讓 P/PA 載於 contact，試跑只有 −0.02，拿掉。開關兩版都跑，用 LOO 決定。

符號錨的選法：每個 factor 選一個群內相關最強、方向最沒爭議的指標當錨。錨**不是**用約束限正：2015 f2 的快速擬合顯示，用絕對值限正時掉進鏡像峰的鏈會被卡住（HR/AB 區間 [0, 0.71]、XBH/H [−0.37, 0.41]、ESS 7），而且取樣慢到走不完。現在負荷量全部自由，取樣後逐鏈依錨的符號把整個 factor 翻成約定方向（`align_signs`）。起始值仍按棒球常識設（`INIT_SIGN`），讓多數鏈一開始就在正確那一面。

四個 factor 之間允許相關：`LKJCorr(η=2)` 的 Cholesky 因子，相關矩陣 Ω 是估計量。預期 power 與 contact 負相關（三振換長打的取捨），其他接近零。Ω 本身是一個發現：球員類型的取捨結構。

## 4. 為什麼不直接用 EFA 的分數

EFA 用的是比例的 z 分數，30 打席和 500 打席的三成一樣重，而且是無監督的。最終模型（`fit_year.py`）是：

- 指標用原始計數與分母，二項／負二項似然，分母自動加權。
- 四個 η 與結果（升級或 WAR）聯合估計，負荷量會偏向與結果有關的方向。
- 層級偏移 γ_jℓ 吸收環境差異，不用事先標準化。

EFA 在這裡的角色是**決定結構**：幾個 factor、哪個指標歸哪、哪些要交叉。這是標準的「探索定結構、驗證估參數」兩步。

## 5. factor 數不足時的併法（`FOLD`）

| `--factors` | 做法 |
|---|---|
| 1 | 15 個指標全部載在一個 η（基準，預期不收斂或負荷量近零） |
| 2 | 接觸 + 力量；選球併入接觸；速度指標不用（11 個指標） |
| 3 | 接觸、力量、速度；選球併入接觸（15 個） |
| 4 | 四個獨立（15 個） |
| 4 + crossload | 加三條交叉負荷 |

這五個是 model comparison 的候選。預期 LOO 排序：4x ≳ 4 > 3 > 2 > 1。如果 4 對 3 的 ΔELPD 小於兩倍標準誤，表示選球在升級決策裡沒有獨立訊號，這本身是結論（球團看保送率只是看上壘率的一部分）。

## 6. 對研究問題的意義

原本問「哪些指標的權重大」，拆成四個 factor 後問題變成兩層：

1. **結構係數 β_k**：球團升級決策對四種能力各看多重？WAR 對四種能力各吃多重？兩組 β 的差就是「球團看重的 vs 真的有用的」，四個數字一張圖，比十五個負荷量好講。
2. **負荷量 λ_j**：每個指標對它所屬 factor 的貢獻。這一層回答「接觸裡面球團看的是 AVG 還是 K%」。

逐年追蹤的也變成四條 β 軌跡，比較容易看到 2015 年 Statcast 之後是否 power 的權重上升、contact 的權重下降。

## 9. 快速版（4 鏈 × 200）：f2、f4、f4x、f4xs，2015

三組四能力版都收斂（0 divergence、Pareto-k 0 筆、β 的 ESS 400–1,000）。

| | f4（簡單結構） | f4x（K%、whiff% 交叉到力量） |
|---|---|---|
| β 打得到球 / 打得遠 / 跑得快 / 選得到球 | +0.57 / **+0.28** / +0.14 / −0.40 | +0.63 / +0.05 / +0.16 / −0.46 |
| 打得到–打得遠相關 | −0.31 | +0.20 |
| LOO M1 / Mh / M0 | −1890 / −1900 / −1950 | −1880 / −1900 / −1950 |

f4x 把「力量型打者三振多」放進打得遠的定義，所以球隊對它的淨權重接近零；f4 把同一件事放在兩種能力的相關裡（打擊與力量的取捨），打得遠是純粹的全壘打與長打。LOO 差 10，在誤差內。**主模型用 f4**（對球探講乾淨：打得到就是打得到，打得遠就是打得遠），f4x 當穩健性檢查。選得到球為負、跑得快為正、打得到球最重，兩版一致。

f2（只有打得到與打得遠，選球併入打得到）：LOO −1940，輸 wOBA 基準；跑得快與選得到球兩塊補上才贏過綜合指標。

球探版（f4xs）：四能力部分與 f4x 相同，β_scout +0.44（ESS 400–1,000），非選秀 −1.16、高中 −0.32、JC −0.22。但 ζ 的兩個負荷量 ESS 6、r-hat 1.9：兩個指標撐一個因子只有三個可觀測動差，差一個約束。已改為「標準化後負荷量大小相等、只估一個 λ ≥ 0」，待重跑。

## 11. 球探版與候選版快速結果（2015，4 鏈 × 200）

**升級，f4s**（球探先驗識別修正後：λ 0.77，ESS 366）：β 打得到球 +0.57、球探評價 +0.46、打得遠 +0.28、跑得快 +0.16、選得到球 −0.41；非選秀 −1.29、高中 −0.18（不顯著）。LOO M1 −1890 ≈ Mh −1890 > M0 −1950。當季的打擊能力比簽約時的評價重。

**WAR 第一段：幾年登上（f4s，log 時間，負 = 快）**：打得到球 −0.42、球探評價 −0.39、打得遠 −0.21、跑得快 −0.10、**選得到球 +0.17（慢）**；非選秀 +0.41、高中 +0.30（慢）。登上時間也是球隊的決定，方向與升級一致。

**WAR 第二段（asinh 尺度，ν = 13.6）**：球探評價 +0.30、打得到球 +0.14、打得遠 +0.13、跑得快 +0.13、**選得到球 0.00（±0.07）**；高中出身 −0.56、非選秀 −0.23。LOO：M1 ≈ Mh −2700 > M0 −2800。

三個結果的尺度不同（勝算、時間、asinh WAR），比形狀：球隊升人時打得到球是其他能力的二到四倍；真相裡三種能力對 WAR 一樣重，球探評價最重。選得到球：球隊扣分、登上變慢、對 WAR 無影響，是「被當成缺點的中性特質」。

**反事實選擇（同層級同人數，2015 同年內）**：A +10、A+ +14、A- +2、AA +3、AAA −11、R/CPX −3 WAR，重疊 60–80%。球隊的升人決定整體上接近模型，差別在邊緣的十幾個人；同年比較偏樂觀，正式版用別的年份驗。

**球探看到的東西**：四種能力只重建 ζ 的 4%（R²）；重建不出的部分與六季 WAR 相關 0.31，ζ 本身 0.32，各 η 0.03–0.07。混淆：高順位本來就被給更多機會，這條路也製造「評價預測 WAR」。

**非線性（結案）**：linear、quad、cubic、spline 四種形狀的 LOO 全是 −1890；spline 的六段係數各自 sd 0.3–0.4，沒有一段明確不為零。只有跑得快的平方項 +0.10（sd 0.04）。正式用線性，平方項列入小效果清單。

**候選變數在 WAR 段**：犧牲觸擊率 −0.19（sd 0.09）、三振率進步 +0.12、全壘打率進步 −0.12、保送率進步 −0.12（sd 0.06–0.07），單年在誤差邊緣，跨年看。

**候選變數（f4se）**：升級：全壘打率進步 +0.13、保送率進步 +0.09、三振率進步 +0.07（小而正）；跨層級的季 −1.07（定義造成：季中已升過，隔年不算再升，當控制項）；打席佔比 −0.41；年資、留級不顯著。幾年登上：有上一季 +0.43（慢；年資效果）、犧牲觸擊率 +0.15（慢）。
