# 理論基礎：貝氏潛在因子模型的數學

> 對應 `model_spec.md`（規格）。本文件解釋每個設計選擇背後的統計理由。

## 1. 為什麼是聯合機率，不是兩段式

兩段式做法：先用 PCA 把十項數據壓成一個分數，再把分數丟進迴歸預測升級或 WAR。問題在於 PCA 是無監督的，它找的是數據之間變異最大的方向，這個方向和「升級」或「WAR」可以毫無關係。

聯合模型寫的是

```
p(結果, 數據, η, λ, β, …) = p(結果 | η, 共變數, β) · p(數據 | η, λ) · p(η) · p(λ, β, …)
```

一次對整個聯合分布推論。後果：

- η 同時受數據和結果約束。負荷量 λ 會偏向那些對結果有解釋力的數據，這正是我們要的「與升級有關的組成」。
- 缺值是未觀測節點，由聯合分布邊際掉，不用先填補。
- Model comparison 比的是整個聯合模型的預測分布。

## 2. 測量模型：廣義線性的因子分析

傳統因子分析假設指標是常態。我們的指標是比例和計數，直接寫對的似然：

```
y_ijt ~ Binomial(n_ijt, p_ijt),   logit p_ijt = α_j + γ_jℓ + λ_j η_it      （比例類）
y_ijt ~ NegBin(μ_ijt, φ_j),       log μ_ijt = log n_ijt + α_j + γ_jℓ + λ_j η_it （計數類）
```

三個效果：

1. **分母自動加權**。30 打席的三成和 500 打席的三成，二項似然的曲率差 17 倍，前者對 η 的約束很弱。不用設門檻，也不會因為刪人引進存活偏差。
2. **連結函數內建「轉換」**。logit 和 log 不是我們選的，是分布決定的。「要不要取 log」的問題消失。
3. **層級偏移 γ_jℓ**。A 級的三振率和 AAA 的三振率基準不同，這一項吸收環境差異，η 才能跨層級比較。

合成指標（wOBA、wRC+、OPS）不直接建模，因為它們是上面這些計數的函數，資訊已在。而且它們在小樣本下極端值是分母造成的，不是能力。

## 3. 識別

因子模型的尺度與符號不識別，需要固定：

- 每個 η_k 的變異數固定為 1（Ω 對角為 1），尺度由此定。
- 符號：因子模型對每個 factor 都有 η_k → −η_k、λ_k → −λ_k 的鏡像對稱，後驗有 2^K 個等價的峰。第一版用絕對值把錨指標限正，結果掉進鏡像峰的鏈被牆卡住（錨貼 0、其他指標反號、每步走到最大樹深）。現在的做法是取樣時不限制，取樣後逐 draw 看錨指標（K% 負、HR/AB 正、SBA/OBT 正、BB% 正）的符號，整個 factor 的 λ、η、β、δ、θ_org、相關矩陣一起翻，等於把參數空間沿對稱面折成一半。似然對這個變換不變，所以 LOO 與 WAIC 不受影響。
- 四 factor 版本用簡單結構識別：每個指標只載在它所屬的 factor（交叉負荷是明確列出的三條例外），factor 之間的相關 Ω 自由估計（LKJ prior）。這等於事先固定旋轉，不需要事後 varimax。為什麼是四個、怎麼分群，見 `factor_plan.md`。

## 4. 結構模型

### 4.1 結果 A：球團的決定（升級）

```
z_it ~ Bernoulli(π_it)
logit π_it = γ_ℓ + β f(η_it) + ρ log pick_i + ω log bonus_i + ψ age_rel_it + u_org(i),t
```

- 順位 ρ 當控制：β 的意義是「給定順位，factor 的增量」。這直接回答「順位之外還剩什麼」。
- f(η) 的形式（線性、二次、樣條）由 model comparison 挑。二次項對應邊際效益遞減；樣條不預設形狀。
- u_org,t 是球團 × 球季的隨機效應，吸收名單壓力、釋出潮等共享衝擊。

### 4.2 結果 B：事後的真相（WAR），hurdle 結構

六季往後看的 WAR 有一個點質量在零（沒登上大聯盟）加一個連續的厚尾分布。用 hurdle：

```
r_it ~ Bernoulli(q_it),                    logit q_it = κ_r + γ_r,ℓ + β_r η_it + ρ_r log pick_i + …
WAR_it | r_it = 1 ~ StudentT(ν, m_it, σ),  m_it = κ_w + γ_w,ℓ + β_w η_it + ρ_w log pick_i + …
```

- 兩段各有自己的 β，可以分開看「factor 讓你更容易上去」和「上去之後打得更好」。
- Student-t 的自由度 ν 由資料估，尾巴厚度不預設。WAR 的第 99 百分位是中位數的 450 倍，常態不能用。
- 六季窗口要完整落在資料內，所以此模型只對 2019 年以前的球季可估。

### 4.3 兩組負荷量的差距

λ^A 在結果 A 下估，λ^B 在結果 B 下估。兩者都是 J 維向量，比較方式：

- 逐指標：λ_j^A − λ_j^B 的後驗分布，看哪些指標被球團高估或低估。
- 整體：‖λ^A − λ^B‖ 的後驗，逐年追蹤。

注意兩組 λ 的尺度相同（η 變異數都固定為 1），可以直接比。

## 5. 競爭風險：離開

下一季去向有多種互斥結果。嚴格的做法是多項 logit：

```
log(π_k / π_same) = κ_k + β_k f(η) + … + u_k,org,t,   k ∈ {promoted, demoted, exit, mlb}
```

目前第一版用二元（升級對其他）把 pipeline 走通，多項版本是 model comparison 的候選。

「離開」的兩種隨機性在模型裡對應：

- 共享：u_exit,org,t 的變異數 τ_exit。2019 到 2021 的尖峰會反映在這裡。
- 個別：Bernoulli 本身的殘差。

β_exit 接近零即證實「離開與能力正交」。

## 6. 序列更新與漂移

每年一個 fit，第 t 年的 prior 是第 t−1 年的後驗，變異數放大 (1+κ)：

```
λ_j^(t) ~ Normal( E[λ_j | D_{t−1}],  (1+κ) Var[λ_j | D_{t−1}] )
```

這是離散時間的貝氏濾波，κ 是遺忘係數。κ = 0 等於把所有年份合併估，看不到漂移；κ 很大等於每年獨立估，吵。用留出年份的預測力挑 κ。2020 停賽：2019 → 2021 跨斷點時 κ 加倍。

輸出是 λ^A(t) 與 λ^B(t) 兩條軌跡，以及它們的距離隨 t 的變化。「球團資料科學進步」的檢驗就是距離是否縮小。

## 7. 階層

```
μ_it = a_i + b_i (t − t_i0) + δ age_rel_it
a_i ~ Normal(θ_org(i) + θ_draft(i), σ_a),  b_i ~ Normal(0, σ_b)
```

- a_i 球員截距、b_i 成長斜率。單一球季的 fit 裡 a_i 與 η_it 不可分，所以單年版本簡化為 η_it ~ Normal(θ_org + δ age_rel, 1)。跨年合併估時才有 b_i。
- θ_org 球團效應：哪隊的球員 factor 系統性偏高。θ_draft 選秀年效應。
- 跨球團比較用負荷量的球團偏移 λ_jo = λ_j + ε_jo，收縮到聯盟共識。

## 8. Model comparison

- PSIS-LOO：以 pointwise log-likelihood 估留一法的 ELPD，Pareto 平滑重要性取樣。留出單位是**整個球員**，不是單一人季，否則同一人其他季在訓練集裡，η 已被估到，ELPD 高估。
- WAIC：`elpd_waic = Σ_i [lppd_i − p_i]`，lppd_i = log mean_s exp(ll_is)，p_i = Var_s(ll_is)。ArviZ 1.x 已移除，自算。
- 兩者理論上估同一量，差異出現時要解釋。報 ELPD 差與其標準誤，差距小於兩倍標準誤視為無法分辨。
- Pareto-k > 0.7 的觀測是 LOO 近似不可靠的點，也是對模型影響最大的個案，列出來逐個看。

候選維度：f(η) 形式、η 維度、有無順位、有無 u_org,t、有無體系外變數。

## 9. Prior

弱資訊 prior，讓資料主導但擋住極端：

```
λ_j ~ Normal(0, 1)（λ_1 ~ HalfNormal(1)）
γ_jℓ ~ Normal(0, 2)（層級截距；不另設 α_j 與 κ，避免只差一個常數的參數對形成山脊）
β, ρ, ω, ψ, δ ~ Normal(0, 1)
σ, τ ~ HalfNormal(1);  φ_j ~ Gamma(2, 0.5);  ν ~ Gamma(2, 0.1)
```

logit 尺度上 Normal(0, 1) 的係數對應勝算比約 0.37 到 2.7 的 68% 區間，對標準化後的共變數是合理範圍。

## 10. 存活與設限

- 最後一季（censored）與離開回來的間隔不進結構似然。
- 最近兩三季的 `gone_exit` 因沒機會回來而偏高，當設限。
- 打席少的人不刪，理由見第 2 節。
- 結果 B 的六季窗口是硬設限，用 `war_observable` 遮罩，不外推。

## 11. 診斷

NUTS 4 鏈，r-hat < 1.01、ESS bulk > 400、divergences = 0 才報結果。η 用中心化參數化：資料對多數球員很強（幾百打席、上千顆球），η 被似然釘住，全域參數（相關矩陣、球團均值）只透過先驗影響它，兩邊脫鉤；非中心化在這種情況反而讓一萬五千個標準常態跟著全域參數一起動，步長極小。η 的變異數固定為 1，沒有要學的尺度，所以沒有漏斗問題。球團效應 θ_org 資料弱，維持非中心化。`--param noncentered` 保留舊版供比較。到最大樹深的比例是取樣效率的早期警訊：超過兩成表示後驗有長山脊，先找只差一個常數的參數對，不要先加 draws。
