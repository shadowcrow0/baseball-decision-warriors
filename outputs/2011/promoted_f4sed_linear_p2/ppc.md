# 後驗預測檢查 · 2011 · promoted_f4sed_linear_p2

從 M1 後驗抽 200 組參數，照模型把每個指標重新生一次，跟真實比。圖：`figures/ppc_2011_promoted_f4sed_linear_p2.png`。

讀法：**p（離散）** 接近 0 = 真實比二項／負二項假設的更散（該換 beta-binomial 或放寬 φ）；離散比 = 真實卡方 ÷ 模型生的卡方，1 是剛好；人多時 p 很嚴，判定以離散比超過 1.1 為準。**p（最大值）** 接近 0 = 真實有模型生不出來的極端人。**KS** = 跨人比率分布的最大落差（20 份平均）。零的比例看零膨脹。
